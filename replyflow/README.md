# صدى — منصة الردود الذكية على التعليقات والرسائل

تستقبل التعليقات والرسائل من فيسبوك وإنستغرام وواتساب وتيليغرام وتيك توك، وترد عليها بالذكاء الاصطناعي:
**رد علني تحت التعليق + رسالة خاصة بالتفاصيل**، لكل المنشورات أو لمنشور محدد، مع لوحة تحكم عربية.

## التشغيل

يلزم Node.js 22.13 أو أحدث. لا توجد حزم للتثبيت.

```bash
cp .env.example .env      # عدّل القيم (اختياري)
node --disable-warning=ExperimentalWarning server.js
# أو: npm start
```

عند أول تشغيل تُطبع **كلمة مرور لوحة التحكم** في الطرفية مرة واحدة (أو حدّدها بالمتغير `ADMIN_PASSWORD`).
افتح `http://localhost:3000` ثم اتبع الخطوات الأربع في «نظرة عامة»:

1. **معلومات النشاط**: الاسم، المنتجات، الأسعار، التوصيل… هذا مصدر الحقيقة الوحيد للذكاء الاصطناعي.
2. **الإعدادات**: مفتاح API للذكاء الاصطناعي (Anthropic أو أي مزوّد متوافق مع OpenAI).
3. **الحسابات**: اربط صفحة/بوت.
4. **الحملات**: أنشئ حملة، ثم جرّبها من صفحة **التجربة** قبل تشغيلها فعلياً.

بدون مفتاح API تعمل المنصة بالنصوص الثابتة (القوالب) فقط.

## كيف تختار المنصة الحملة

عند وصول تعليق تُختار أنسب حملة مفعّلة (القناة والحساب والمنشور والكلمات المفتاحية يجب أن تطابق):

| الأولوية | السبب |
|---|---|
| الأعلى | حملة مخصّصة لـ **منشور محدد** |
| ثم | حملة لها **كلمات مفتاحية** |
| ثم | حملة مخصّصة لحساب أو قناة |
| الأدنى | حملة عامة لكل المنشورات |

كل حملة تحدد: الرد العلني (ذكاء اصطناعي / نص ثابت / بدون) والرسالة الخاصة (كذلك) والتفاصيل المرسلة، وخيار «مرة واحدة لكل شخص».
في النص الثابت: `{name}` اسم الشخص و`{details}` التفاصيل، وافصل بين عدة صيغ بسطر فارغ لتتبدّل عشوائياً.

## الربط بكل قناة

### فيسبوك وإنستغرام وواتساب (Meta)
1. أنشئ تطبيقاً في [Meta for Developers](https://developers.facebook.com) وأضف منتجات Messenger وInstagram وWhatsApp حسب حاجتك.
2. في **Webhooks** ضع عنوان الاستدعاء ورمز التحقق الظاهرين في صفحة «الحسابات» (يجب أن يكون الموقع على HTTPS عام).
   - الصفحة: اشترك في `feed` و`messages`.
   - إنستغرام: اشترك في `comments` و`messages`.
   - واتساب: اشترك في `messages`.
3. ضع **App Secret** في الإعدادات (يتحقق النظام من توقيع كل طلب).
4. في «الحسابات» أضف الحساب بمعرّفه (Page ID / Instagram ID / Phone Number ID) والتوكن.
   الصلاحيات: `pages_messaging`, `pages_manage_engagement`, `pages_read_engagement`, `instagram_basic`, `instagram_manage_comments`, `instagram_manage_messages`. تحتاج غالباً إلى **مراجعة التطبيق** من ميتا قبل العمل مع العامة.

قيود ميتا المهمة: الرسالة الخاصة على تعليق (Private Reply) **مرة واحدة لكل تعليق وخلال 7 أيام**، والرد على رسائل الصندوق ضمن **نافذة 24 ساعة** من آخر رسالة للعميل، وواتساب يتطلب قوالب معتمدة خارج النافذة.

### تيليغرام
أنشئ بوتاً من BotFather، أضفه كحساب، ثم اضغط **تفعيل الويب هوك** (يتطلب HTTPS عاماً).
- الرسائل الخاصة للبوت = رسائل. الرسائل في المجموعات = تعليقات (أضف البوت لمجموعة النقاش المرتبطة بقناتك).
- لا يستطيع البوت مراسلة شخص على الخاص قبل أن يبدأ هو المحادثة، فقد تفشل «الرسالة الخاصة» لمن لم يفعل.

### تيك توك
لا توجد واجهة عامة مفتوحة للرد على التعليقات والرسائل. لذلك تعمل المنصة كـ**جسر**:
- **الاستقبال**: يرسل نظامك المعتمد (واجهة شريك رسمية أو أداة أتمتة) POST إلى `/webhook/tiktok/<رقم الحساب>` مع الترويسة `x-webhook-secret` (السر في صفحة الحسابات):
  ```json
  {"kind":"comment","post_id":"7300","comment_id":"c1","user_id":"u9","user_name":"سارة","text":"بكم السعر؟"}
  ```
  (`kind` إما `comment` أو `message`، ويمكن إرسال مصفوفة داخل `events`).
- **الإرسال**: تُرسل المنصة أمر الرد إلى `outbound_url` الذي تحدده:
  ```json
  {"action":"reply_comment | private_message","post_id":"…","comment_id":"…","user_id":"…","text":"…"}
  ```
  موقّعاً بـ HMAC-SHA256 في ترويسة `x-signature` إن حدّدت سراً.

## الحماية المدمجة

- لوحة التحكم بكلمة مرور (تُخزَّن مشفّرة) وجلسات `HttpOnly` وحد للمحاولات الخاطئة، وترويسات أمان وCSP.
- التحقق من توقيع ميتا، وسر لكل ويب هوك تيليغرام وتيك توك.
- منع المعالجة المكررة للتعليق نفسه، ولا يرد على تعليقات صفحتك نفسها ولا على الردود المتداخلة.
- تأخير بشري عشوائي قبل الرد، وحد أقصى للردود في الساعة لكل حساب، وحد للرسائل لكل شخص.
- نص العميل يُعامل كبيانات لا كأوامر للنموذج، ولا يُسمح باختلاق أسعار أو روابط خارج «المعلومات المعتمدة».
- طلب «موظف/شكوى…» يحوّل المحادثة بدل أن يجيب الذكاء الاصطناعي.

## ملاحظات النشر

- يخزّن كل شيء في `data/app.db` (SQLite)؛ احتفظ بالمجلد `data/` على قرص دائم وخذ نسخة احتياطية منه.
- التوكنات ومفتاح API مخزّنة في قاعدة البيانات دون تشفير إضافي: احمِ الخادم والمجلد، واستخدم HTTPS (خلف Nginx/Caddy أو منصة استضافة).
- التأخير العشوائي يعتمد على الذاكرة: إعادة تشغيل الخادم أثناء الانتظار قد تُفقد ردوداً قيد الانتظار.
- الاختبار: `npm test`.
- احترم سياسات المنصات: الرد الآلي على من تفاعل معك فقط، وبلا إغراق.

## الهيكل

```
server.js            الخادم والمسارات والويب هوك
src/engine.js        اختيار الحملة، توليد الردود، الإرسال، السجل
src/ai.js            الاتصال بنموذج الذكاء الاصطناعي
src/db.js            قاعدة البيانات (SQLite)
src/channels/        ميتا، تيليغرام، تيك توك
public/              لوحة التحكم
test/smoke.js        اختبار شامل
```
